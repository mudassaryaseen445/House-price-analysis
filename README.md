# House-price-analysis
Exploratory data analysis and preprocessing of house price data using Python, Pandas, Seaborn, and Matplotlib.
# Project Overview
This project focuses on exploratory data analysis (EDA) and preprocessing of a House Price dataset using Python. The project analyzes residential property features, identifies data-quality issues, handles missing values, examines zero values, encodes categorical variables, and explores relationships between different features using correlation analysis and visualizations.
# Purpose
The main purpose of this project is to clean, understand, and prepare the house price dataset for machine learning applications. The analysis helps identify important data-quality issues and understand the relationships between property features, providing a strong foundation for developing a house price prediction model.
# Workflow
- Data Loading – Import and load the house price dataset.
- Data Understanding – Examine dataset shape, columns, data types, and basic statistics.
- Data Quality Analysis – Identify missing values, duplicate records, and zero values.
- Data Cleaning – Handle missing values and remove unsuitable or low-information features.
- Feature Preprocessing – Convert categorical variables into numerical form.
- Exploratory Data Analysis – Analyze numerical features and their relationships.
- Correlation Analysis – Calculate feature correlations and visualize them using heatmaps.
- Data Preparation – Produce a cleaned and analysis-ready dataset for future machine learning tasks.
# Technologies Used
- Python – Main programming language
- Pandas – Data manipulation and preprocessing
- NumPy – Numerical operations
- Matplotlib – Data visualization
- Seaborn – Statistical visualization and correlation heatmaps
- Scikit-learn – Feature preprocessing and encoding
- Jupyter Notebook – Development and analysis environment
